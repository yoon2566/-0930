# 정상까지 점프!

**발판 20개를 올라 정상에 도착하는 완성된 3D 게임 하나입니다.**

- 시작 발판부터 정상까지 20개 발판, 19번의 점프
- 중간 쉼터 3개와 낙하 후 복귀
- 좁은 발판과 방향이 꺾이는 산길
- 제공 3D 캐릭터, GLB 캐릭터 교체, 시범 등반

## 실행

Node.js 20 이상이 설치된 컴퓨터에서 `START.cmd`를 실행하거나 이 폴더에서 다음 명령을 실행하세요.

```text
node start.mjs
```

**로컬 서버가 실행된 뒤** 크롬에서 http://127.0.0.1:4195/ 를 열고 **등반 시작**을 누릅니다. HTML 파일을 더블클릭해서 실행하는 방식은 아닙니다. npm 패키지를 별도로 설치할 필요는 없습니다.

OpenCode에 요청할 때:

```text
https://github.com/yoon2566/-0930 저장소의 최신 버전을 새 폴더에 내려받고 AGENTS.md를 읽어서 완성 게임을 실행해줘. 기존 폴더는 덮어쓰지 마. 코드는 바꾸지 말고 접속 주소를 알려줘.
```

## 조작

| 키 | 동작 |
|---|---|
| WASD / 방향키 | 이동 |
| Space | 점프 |
| R | 마지막 쉼터로 복귀 |
| Esc | 일시 정지 |

**시범 등반 보기**를 누르면 같은 코스를 자동으로 올라갑니다. **캐릭터 바꾸기**에서 다른 GLB 파일을 적용할 수 있습니다.
