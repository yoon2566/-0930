# 정상까지 점프

**OpenCode에 한 문장씩 입력하며 만드는 3D 게임 수업.**

준비: Node.js 20 이상, Git, Chrome, OpenCode와 연결된 AI 모델. 수업 기준 모델은 OpenRouter의 DeepSeek V4.1 Flash입니다. API 키는 각 컴퓨터의 OpenCode에 연결하며 저장소에 넣지 않습니다.

## 처음 한 번

OpenCode에 아래 문장을 입력하세요.

```text
https://github.com/yoon2566/-0930 저장소를 peak-jump-classroom 폴더에 내려받아줘. 이미 있으면 덮어쓰지 말고 그 폴더를 사용해줘. 내려받은 AGENTS.md를 읽고 node start.mjs로 실행해줘. 지금은 게임 기능을 추가하지 말고 접속 주소만 알려줘. 이후 요청도 이 프로젝트의 AGENTS.md와 prompts.json 규칙에 맞춰 작업해줘.
```

게임 주소: http://127.0.0.1:4195/

처음에는 캐릭터와 시작 발판만 보이고 아직 움직이지 않습니다. 아래 요청을 **하나씩** 입력하고 끝날 때마다 브라우저를 새로고침해서 직접 확인하세요.

## 단계별 프롬프트

### 1. 이동
```text
캐릭터를 방향키로 움직이게 해줘.
```
확인: 방향키로 움직이고 손을 떼면 멈춥니다.

### 2. 점프
```text
스페이스를 누르면 점프하게 해줘.
```
확인: 바닥에서 점프하고 다시 내려옵니다.

### 3. 산길
```text
정상까지 점프해서 올라갈 발판 5개를 만들어줘.
```
확인: 산길과 정상 깃발이 나타납니다.

### 4. 난이도
```text
너무 쉬워. 2번과 4번 발판을 좁혀줘.
```
확인: 두 발판이 작아집니다.

### 5. 쉼터
```text
3번 발판을 쉼터로 만들어줘. 떨어지면 거기서 다시 시작하게 해줘.
```
확인: 쉼터에 도착한 뒤 떨어지면 그곳으로 돌아옵니다.

### 6. 캐릭터
```text
준비된 3D 캐릭터로 바꿔줘. 움직일 때 달리는 동작도 넣어줘.
```
확인: 외형이 바뀌고 멈추면 대기, 움직이면 달리기 동작을 합니다.

## 선생님

- 원래 완성 게임: http://127.0.0.1:4195/teacher/
- 복사 버튼이 있는 프롬프트 화면: http://127.0.0.1:4195/lesson.html
- 다음에 켤 때: `START.cmd`. 프로젝트 전용 AI 설정으로 시작할 때: `OPEN_AI.cmd`.
- 렌더링·카메라·중력·충돌·자산·서버를 제공합니다. 학생은 이동·점프·발판·쉼터·캐릭터 동작 연결 코드를 직접 만듭니다.
- 처음 내려받기와 모델 연결은 수업 전에 마칩니다. 단계별 목표는 1~2분이며 컴퓨터·네트워크·AI 응답에 따라 달라집니다.
- 게임 실행에는 npm 설치가 필요 없습니다. 원본 GitHub에 학생 수정 내용을 자동으로 올리지 않습니다.
